# ShieldLabs

Anonymous visitor identification and fraud-prevention platform. A browser JS snippet collects 100+ signals and returns a persistent visitor/device ID plus an explainable 0-100 risk score; the customer's own code makes the allow/challenge/block decision. Offers server-side REST APIs (History and Management), outbound webhooks, and agent-readable llms.txt documentation.

- **Provider:** https://shieldlabs.ai

## APIs

- **ShieldLabs Server API** — Server-side REST APIs: History API (base https://account.shieldlabs.ai/api, Bearer sec_ key) for reads that do not consume paid requests, and Management API (base https://api.shieldlabs.ai, Bearer secret + X-Shield-Domain) for domain profile, balance, and per-row-billed history. Also outbound webhooks pushing score/signals. Documented narratively with curl examples; no machine-readable OpenAPI/AsyncAPI/GraphQL/Postman contract found publicly. (`https://api.shieldlabs.ai`)
